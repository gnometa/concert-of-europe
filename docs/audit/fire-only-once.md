# `fire_only_once = yes` on multi-country events

`fire_only_once` is engine-wide: the event fires **once per game, for one
country, under any circumstance** (`docs/wiki/list-of-conditions.md:138`). Any
self-firing (MTTH) `country_event` whose trigger admits more than one country
therefore fires for exactly one of them, ever — unless it is deliberately a
single world outcome.

Generated by `python scripts/audit_fire_once.py` (parser from `refcheck.py`).
Only self-firing `country_event`s with `fire_only_once` and **no bare
`tag = X` / `owns = <province>`** at the top level of the trigger are listed;
`owns` counts as identifying because only one country owns a province.

## Counts (after the fixes below)

| Class | Meaning | Count |
|---|---|---|
| A | trigger has an `OR` of `tag =` tests | 80 |
| B | culture / culture_group / continent / GP / government test only | 10 |
| C | no country-identifying trigger — genuine world event | 37 |
| | total | 127 |

Before the fixes: A 85, B 13, C 37 (135).

## Class A — verdict: overwhelmingly *not* defects

Almost every class-A `OR` is a set of **alternative tags for the same nation**,
only one of which can exist in a game: `OR(ENG,ENL)` x35, `OR(SPA,SPC,IBR)` x8,
`OR(AUS,KUK)` x8, `OR(PRU)` x8, `OR(USA,CSA,FSA)` x7, `OR(POR,UPB)` x3,
`OR(BRZ,UPB)` x2, `OR(PRU,PZN)`, `OR(JAP,TKG)`, `OR(GCO,CLM)`,
`OR(CHI,TPG,KMT)`, `OR(KMT)`. For those `fire_only_once` behaves exactly like a
per-country guard, so they are left alone. `CHIFlavor.txt` 164599/131715 use
`OR = { AND = { tag = QNG ... } ... }` with mutual `NOT = { exists = ... }`,
i.e. also one country at a time.

Fixed (flag guard already present, `fire_only_once` redundant and harmful):

- `CoE_RoI_R/events/Sepoy rebellion.txt:41` 90040 — `OR(ENG,ENL,primary_culture=british)`
  — **defect** (several British-culture nations can hold Indian provinces) — dropped
  `fire_only_once`; trigger already `NOT`s `sepoy_rebellion` / `sepoy_rebellion_ended`.
- `CoE_RoI_R/events/PRUFlavor.txt:468` 34609 — `OR(tag=PRU, capital=549)` — **defect**
  — dropped; trigger already `NOT`s `MozartFest1838`.
- `CoE_RoI_R/events/PORMiguelistGVG.txt:16,170,258` 1001000/1001001/1001002 —
  `OR(POR,UPB)` — redundant — dropped; each trigger already `NOT`s the flag its
  options set (`por_charter_granted`, `por_liberal_war`, `por_charter_upheld`).

Left as intended world events:

- `2nd_grand_revolution.txt:150` 99921 — `OR(FRA,RUS,flag)` — the dissolution of
  Germany happens once globally; the option clears the global flags.
- `ARAFlavor.txt:554` 96110 "The House of Saud Returns" — `OR(HAL,HDJ,ASR)` — one
  Saudi restoration per game.

Ambiguous, **not** touched (listed for a human):

- `CSAFlavor.txt:514,548,584` 16650/16651/16652 — `OR(USA,CSA,FSA,TEX)`. USA and
  CSA/TEX *can* coexist after the ACW, so one of them silently loses the flavour
  event. Low impact (Passenger Elevator / Barnum / Standard Time).
- `ITARisingsGVG.txt` and `JavaWarGVG.txt` — being edited by another agent; their
  cases were not inspected here.

## Class B — the real defect class

Fixed:

- `CoE_RoI_R/events/2nd_grand_revolution.txt:381` 99916 "Intervention in Germany"
  — any non-vassal European monarchy not in the excluded tag list — **defect**: the
  event is explicitly generic ("Our government is of the opinion...") and each
  country is supposed to be able to declare war on GER, but only one ever could.
  Fix: dropped `fire_only_once`, added `NOT = { has_country_flag =
  intervened_in_germany }` to the trigger and `set_country_flag =
  intervened_in_germany` to **both** options (the refusal must also latch, or the
  event re-fires every month).
- `CoE_RoI_R/events/PORFlavor.txt:1996` 97031 "Intervention in Portugal?" — any
  European GP with a liberal/HMS government while POR is an absolute monarchy —
  **defect**: per-country text and per-country cost (money, influence, prestige).
  Fix: dropped `fire_only_once`, added `NOT = { has_country_flag =
  por_intervention_considered }` and set that flag in both options.
- `CoE_RoI_R/events/newEvents.txt:2603` 810029 "Immigrant Surge!" — `continent =
  north_america / south_america / oceania` — **defect**: the trigger already
  `NOT`s `has_country_flag = immigration_surge` (set by the only option) *and*
  the `land_of_opportunity` modifier, so `fire_only_once` did nothing but cap the
  whole New World at one surge. Fix: dropped `fire_only_once`.

Remaining B cases — verdict *intended world event* or self-disabling, not touched:

- `Desert_reclamation.txt:293,371,670` 300959/300964/300979 — `civilized = yes` /
  `is_greater_power = yes`, but each is gated on a specific province being
  `empty = yes` and the option secedes it, so the trigger disables itself for
  everybody; `fire_only_once` is redundant, not harmful.
- `CHIFlavor.txt:50,2596` 164599/131715 — see class A note (one Chinese tag at a
  time).
- `ENGFlavor.txt:1969` 36942 "The Fencibles" — gated on holding every NZL core with
  NZL not existing; effectively one country, and the option hardcodes `ENG_2509`.
- `LANFlavour.txt:88` 190133 — gated on `has_country_modifier =
  lanfang_republic_modifier` (unique) and the option removes it.
- `SWHFlavor.txt:440` 90055 — a GP absorbing Schleswig-Holstein; only one country
  can, and the outcome is global. Ambiguous but left alone. (Note: its `title`
  points at `EVTNAME90054`, a separate pre-existing bug.)
- `MostlyHarmless.txt:2` 23300 "Mysterious Whale Sinks Ship!" — a deliberate
  once-per-game Moby Dick joke chain.
- `PORFlavor.txt:830` 97020 "The Republican Coup D'Etat" — reachable only by a
  non-GP HMS government while the Portuguese chain runs; ambiguous, left alone.

## Class C

the ideology-enabling events 1000-1004, the canal chain, `newEvents.txt`
1100132-1100143, ...). These are world events; `fire_only_once` is correct.
No action.
