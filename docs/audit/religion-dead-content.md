# Audit: dead religion content

Generated by `scripts/audit_religion.py` (read-only). Data: `CoE_RoI_R/history/pops/1821.9.1`
(62 files), `history/countries` (522 files), `events/`, `decisions/`, `inventions/`,
`technologies/`, and `common/{issues,rebel_types,triggered_modifiers,national_focus,cb_types}.txt`.

## 1. What pops actually carry

`CoE_RoI_R/common/religion.txt` is not vanilla: it defines **43 groups / 293 "religions"**,
almost all of which are culture and sub-culture names (`north_german`, `albanian`,
`south_italian`, ...). The 14 real vanilla religions (`catholic`, `protestant`, `orthodox`,
`coptic`, `sunni`, `shiite`, `jewish`, `mahayana`, `gelugpa`, `theravada`, `hindu`, `sikh`,
`shinto`, `animist`) are *still defined*, so any script naming them parses cleanly - they are
simply never assigned to a pop.

| measure | value |
|---|---|
| live (uncommented) `religion =` entries in 1821.9.1 pops | **21026** |
| distinct live values | 259 |
| live values that are culture names in `common/cultures.txt` | **257 of 259** |
| live values that are real religions | **2** (`sunni` x1, `shiite` x1 - stray leftovers) |
| commented-out `#religion = <real religion>` entries | **21076** |

The two survivors are single pops in `history/pops/1821.9.1/India.txt` and
`.../Persia Afghanistan Baluchistan.txt`. Everything else was mechanically commented out and
replaced with the pop's sub-culture. So the pop-religion axis is, in practice, a second
culture axis; **no pop-scope test against a real religion can ever be true.**

## 2. Country state religion (this still works)

`history/countries/*.txt` sets `religion = X` at **country scope** = the state religion. All 522
files use it and every value is defined: protestant 148, sunni 115, catholic 110, animist 36,
hindu 27, orthodox 25, mahayana 20, theravada 10, shinto 8, shiite 7, coptic 6, gelugpa 5,
jewish 1, sikh 1, plus mod religions mormon 1 and ibadi 1.

Consequence: **country-scope `religion = X` triggers and effects are valid and unaffected.**
Only pop-scope tests (`has_pop_religion`, `pop_majority_religion`, and `religion = X` inside
`any_pop` / `*_strata` / pop scope) are dead.

## 4. Remediation options

### (A) Restore real religions to pops

Un-comment `#religion = X` in the 21076 pop entries and move the sub-culture elsewhere. The
un-commenting itself is a ~30-line script over 62 files (**1-2 h** including a deployed smoke
test). The hard part is the sub-culture: the `culture` field cannot hold `north_german`, because
`common/cultures.txt` defines only the 272 real cultures. Writing `culture = north_german` means
adding ~257 sub-cultures as *cultures*, which changes accepted-culture, pop-promotion and
nationalism behaviour, breaks every `is_culture_group` / `add_accepted_culture` in the mod, and
needs new culture-group assignments, party/leader data and localisation. So the sub-culture data
either (i) is discarded, losing the regional-identity mechanic the mod was built around, or
(ii) is promoted to real cultures - a mod-wide redesign. Realistic effort: **1-2 h mechanical,
2-4 weeks** for the culture-model rework and rebalance behind it. Not worth it unless the design
intent has actually changed.

### (B) Keep pops as they are; fix the 134 dead tests

Per site: replace `has_pop_religion = catholic` with the intended culture test
(`has_pop_culture = ...`, `is_culture_group = ...`) where the intent is legible, or delete the
condition where it was pure flavour. Fix the 10 dead negatives first - they are real behaviour
bugs, not just dead code. The 5 country-scope effects need no change; also comment out the 2
stray real-religion pops. Effort: **~1 day** for the 32 sites outside `PERFlavour_five_x.txt`
(each needs a judgement call about intent), plus **1-2 days** for the 107-site Persian chain,
which needs a design decision - its whole Sunni/Shiite sectarian mechanic must be re-expressed
against Persian sub-cultures or dropped.

**Recommended: (B)**, staged - (1) the 10 dead negatives + 2 stray pops (~2 h, fixes real
behaviour), (2) the remaining non-Persian dead triggers (~1 day), (3) a separate decision on the
Persian chain.
