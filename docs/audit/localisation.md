## Load order: which file wins

`docs/wiki/localisation.md` (Common Modding Issues) says that to replace a key your csv
must sort **lexicographically before** the file that already defines it ("to replace
`small_arms_production_desc` defined in `beta1.csv`, your file name must be less than
`beta1.csv`"). So the **alphabetically first file defining a key wins**; later
definitions are dead text -- consistent with the mod naming overrides `00_PDM_*`,
`000_*`, `0000_*`. Conflicts below are listed winner-first.
