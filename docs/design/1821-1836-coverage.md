# 1821-1836 content coverage audit

Scope: every `country_event`/`province_event`/decision in `CoE_RoI_R/events/` and
`CoE_RoI_R/decisions/` whose trigger contains a `year = 182x/183x` gate, plus
undated chains that are explicitly about an 1820s-30s episode. Method: brace-matched
block scan for `year = 18[23][0-9]`, plus a keyword sweep for named episodes.
Counts exclude the twelve `*_setup` decisions (all `year = 1821` bookmark plumbing)
and generic pulse/workplace events.

Legend: **yes** = playable chain exists, **partial** = fires but abstracted, wrongly
dated, or with no player branch, **missing** = nothing.

## Prioritised additions (10)

1. **Zollverein 1834 (PRU plus the German minors).**
   Prussia's 1818 tariff law grew into the Zollverein on 1 January 1834, binding the
   middle states to Berlin economically a generation before political unification.
   Mechanic: decision `found_the_zollverein` (PRU, 1828+, prestige gate) setting
   `set_global_flag = zollverein`, then an event to each German minor offering entry
   (`add_country_modifier` for tax/trade, `relation = 50`, `set_country_flag`).
   Player branch: minors accept (economic modifier, Prussian orbit) or refuse
   (prestige kept, Austria keeps influence).
   Files: `decisions/Germany.txt`, new `events/ZollvereinGVG.txt`, a loc csv, `events/GVG Event IDs.txt`.
   Risk: sphere manipulation is weak in Vic2 script; use `add_country_modifier` and
   `relation` rather than trying to force spheres.

2. **Catholic Emancipation 1829 and the Great Reform Act 1832 (ENG).**
   O'Connell's election forced the Roman Catholic Relief Act; the 1832 Act swept away
   the rotten boroughs and widened the franchise.
   Mechanic: two events (1828+ and 1831+), each offering a reform vs refusal, using
   reform effects that exist in this mod's `common/issues.txt`.
   Player branch: reform now (militancy down, conservative support down) or resist
   (Irish province militancy via `add_province_modifier`, forced event later).
   Files: new `events/ENGFlavorGVG.txt`, loc csv, ID registry.
   Risk: reform names must be read from this mod's `common/issues.txt`, not vanilla.

3. **November Uprising 1830-31 (RUS/POL).**
   Warsaw cadets rose in November 1830, the Sejm deposed Nicholas I, and defeat in
   1831 ended the Congress Kingdom's autonomy.
   Mechanic: replace the single `events/RUSFlavor.txt:95070` with a three-event chain
   gated `year = 1830 NOT = { year = 1833 }` - revolt fires, Russia chooses to crush
   (repression modifier, cores retained) or concede the Organic Statute.
   Player branch: as POL, fight on vs negotiate; as RUS, military rule vs statute.
   Files: `events/RUSFlavor.txt` or new `events/POLUprisingGVG.txt`, `events/POLflavor.txt`.
   Risk: 95070 currently requires `CPL = { vassal_of = THIS }`; confirm CPL exists at
   the 1821 start and verify Polish province IDs against `map/definition.csv`.

4. **Auspicious Incident 1826 (TUR).**
   Mahmud II destroyed the Janissary corps in June 1826, clearing the way for a
   European-style army.
   Mechanic: one event 1826+ with two options - abolish (army organisation modifier,
   one-off prestige/militancy cost, sets a flag) or delay (keep a penalty modifier).
   Player branch: reform the army now at the price of revolt risk, or keep the corps.
   Files: `events/Ottoman_Event.txt` or a new GVG file, `decisions/TUR.txt`, loc csv.
   Risk: do not make the new flag a prerequisite for `tanzimat_reforms` - additive only.

5. **Miguelist / Portuguese Liberal Wars 1828-34 (POR/UPB).**
   After John VI's death Dom Miguel usurped the throne in 1828; Pedro's landing at
   Mindelo in 1832 and the Quadruple Alliance settled it at Evoramonte in 1834.
   Mechanic: continue from `events/PORFlavor.txt:97030` with usurpation (1828),
   Pedro's return (1832, requires the BRZ abdication flag), settlement (1834).
   Player branch: absolutist vs constitutional government, with ENG/FRA intervention
   events mirroring the Carlist 37710 pattern.
   Files: `events/PORFlavor.txt`, an `events/ENGFlavor.txt` hook, loc csv.
   Risk: interacts with the UPB/BRZ split - only fire once UPB has lost Brazil.

6. **Nullification Crisis 1832-33 (USA).**
   South Carolina declared the 1828 and 1832 tariffs void; Jackson's Force Bill and
   Clay's compromise tariff defused it.
   Mechanic: 1832 event - enforce (southern province militancy via
   `any_owned_province = { limit = { is_core = CSA } add_province_modifier = ... }`)
   or compromise (tariff modifier, prestige loss). Sets a flag.
   Player branch: the flag is read (optionally) by the existing ACW chain.
   Files: `events/USAFlavorGVG.txt`, a read-only hook in `events/ACW.txt`, loc csv.
   Risk: do not alter ACW trigger logic; only add an optional flag check.

7. **Monroe Doctrine 1823, USA side (USA).**
   Only the Chilean-side `events/ChileanEvents.txt:198260513` exists today, and it is
   keyed on a `monroe_doctrine2` flag that nothing sets in 1823.
   Mechanic: a USA event gated `year = 1823` that sets `monroe_doctrine1/2` itself,
   plus a British reaction event.
   Player branch: proclaim (prestige, South American relations) or stay silent.
   Files: `events/USAFlavorGVG.txt`, loc csv.
   Risk: find what currently sets `monroe_doctrine2` so the Chilean chain cannot
   double-fire.

8. **Java War 1825-30 (NET).**
   Diponegoro's revolt cost the Dutch roughly 15,000 troops and led directly to the
   Cultuurstelsel forced-cultivation system in 1830.
   Mechanic: province events on Java adding a rebellion modifier, then an 1830
   decision `cultuurstelsel` trading pop militancy for RGO output.
   Player branch: conciliate (fewer revolts, less revenue) vs forced cultivation.
   Files: a new file under `events/DIM/`, `decisions/DIM_East_Indies.txt`, loc csv.
   Risk: DIM is a submod with its own province set - verify every Java province ID in
   `map/definition.csv` before use (this is the historical crash source in this repo).

9. **Daoguang opium edicts 1821-1836 (QNG).**
   Daoguang's reign opened with silver outflow and repeated prohibition edicts; the
   1836 legalisation debate led straight to Lin Zexu.
   Mechanic: two events (1821 accession and fiscal crisis; 1836 legalise-vs-suppress
   debate) feeding the existing `local_opium_habit` modifier and setting a flag that
   the 1839 `events/CHIFlavor.txt:1316080+` chain can read.
   Player branch: legalise and tax, or suppress (raises the severity of the existing
   Opium War chain).
   Files: `events/CHIFlavor.txt`, loc csv.
   Risk: 1316080-1316097 assume an unmodified start - add flags, do not re-gate them.

10. **Italian revolutions 1820-21 and 1831 (SIC, SAR, PAP, MOD).**
    Carbonari risings in Naples and Piedmont were crushed by Austria in 1821, and the
    Romagna rose again in 1831.
    Mechanic: one shared event file - a constitution is granted and then revoked under
    Austrian pressure, with an AUS intervention event mirroring
    `decisions/France.txt:restore_spanish_absolutism`.
    Player branch: grant a constitution (liberal militancy down, Austrian relations
    down, invasion risk) or call in Austria at once.
    Files: new `events/ITARevolts1821GVG.txt`, an `events/AUSFlavor.txt` hook, loc csv.
    Risk: SIC/SAR/PAP have no flavour files at all, so every loc key and picture is
    new; keep ids in a free GVG range (1000600+) and register them.
