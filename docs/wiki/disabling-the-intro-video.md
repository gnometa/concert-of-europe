# Disabling the intro video

Source: https://vic2.paradoxwikis.com/Disabling_the_intro_video

The intro video can be disabled by removing or renaming the movies folder in the Victoria II folder.  

Renaming it is recommended, as that ensures you can always restore it.  

If you remove the folder it will be gone forever unless you uninstall and reinstall the game.

In steam the two files can be found at: C:\Program Files (x86)\Steam\steamapps\common\Victoria 2\movies
