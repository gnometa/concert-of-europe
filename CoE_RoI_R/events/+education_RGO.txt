########################################################################
# RGO EDUCATION LADDER  (9999959-9999969)
#
# Eleven province events, one per state-literacy bucket.  Each one tests
#     has_global_flag = education_setup
#     NOT = { has_province_modifier = RGO_education_<N> }
#     state_scope = { literacy = <lo>  NOT = { literacy = <hi> } }
# and, when it fires, re-stamps EVERY province of the state
# (state_scope = { any_owned = { ... } }) with RGO_education_<N> after
# removing the other ten.  So it is a classifier, not a random event:
# the modifier on a state is meant to be whichever bucket its current
# literacy falls in, and the ladder is the code that keeps it in sync.
#
# id      modifier            state literacy bucket
# 9999959 RGO_education_0     0.00 - 0.10
# 9999969 RGO_education_1     0.10 - 0.20
# 9999968 RGO_education_2     0.20 - 0.30
# 9999967 RGO_education_3     0.30 - 0.40
# 9999966 RGO_education_4     0.40 - 0.50
# 9999965 RGO_education_5     0.50 - 0.60
# 9999964 RGO_education_6     0.60 - 0.70
# 9999963 RGO_education_7     0.70 - 0.80
# 9999962 RGO_education_8     0.80 - 0.90
# 9999961 RGO_education_9     0.90 - 0.99
# 9999960 RGO_education_10    0.99 +
#
# 2026-09-06: converted from self-firing to is_triggered_only.
#
# Before: no is_triggered_only, mean_time_to_happen = { months = 1 } on
# all eleven.  The trigger of a self-firing event is evaluated once per
# province per day regardless of its MTTH, so this cost 11 state_scope
# literacy aggregates x ~2700 owned provinces every day (~119k of the
# mod's ~1.09M modelled clause-evals/day, see docs/audit/performance.md).
#
# After: is_triggered_only = yes.  Every trigger clause is unchanged and
# is still evaluated - the same clauses now sit in the dispatch `limit`
# in events/00_CoE_RoI.txt 99997 (the quarterly economy pulse, fired
# from on_quarterly_pulse), which runs, once per state rather than once
# per province so a human player gets one popup per state and not one per
# province (state_scope = { random_owned = { ... } } is the vanilla idiom,
# events/TemperanceLeague.txt 130):
#     any_country = {
#         limit = { has_global_flag = education_setup }
#         any_state = {
#             random_owned = {
#                 limit = { <the other two trigger clauses> }
#                 province_event = { id = N }
#             }  x11
#         }
#     }
# The event's own trigger block is re-checked when it is fired.
#
# RATE MAPPING - months = 1 (self-firing) -> deterministic, once per
# quarterly pulse.  No `random`/`random_list` chance is introduced,
# because there is no rate to preserve: the trigger is a state's own
# literacy bucket, which does not stop being true if the event does not
# fire today, so the event was certain to fire, and the MTTH only set how
# long a state carried a stale modifier.  What changes is that latency.
#   old: months = 1 per province, and a state's provinces roll
#        independently while any one of them re-stamps the whole state,
#        so a k-province state resynced in ~30/k days on average
#        (~8-15 days for a typical 2-4 province state).
#   new: at the next on_quarterly_pulse, i.e. within 0-91 days, ~45 days
#        on average, deterministically.
# Net effect on gameplay: a state that crosses a literacy decile keeps
# its previous RGO_education_* modifier for up to one quarter instead of
# up to a month or so.  Nothing else about the mechanic changes - the
# same states end up with the same modifiers.  This is the change flagged
# as needing sign-off in docs/audit/performance.md ("Suggested shape for
# a later pass", item 1); it is dispatched quarterly rather than the
# yearly suggested there, to keep the added latency to a quarter.
########################################################################
