#########################################################
#                                                       #
#   Bankruptcy and the Provincial Estates (GVG)         #
#   Denmark, 1821-1836 - ids 1003200-1003204            #
#                                                       #
#   The long fiscal aftermath of the 1813 statsbankerot #
#   Uwe Jens Lornsen's 1830 pamphlet, and Frederick     #
#   VI's rescript of 28 May 1831 creating the four      #
#   consultative provincial estates. DEN owns none of   #
#   Schleswig or Holstein at 1821 - SWH is the vassal   #
#   that holds 369, 370 and 371 - so every effect in    #
#   the duchies is scripted through SWH, never through  #
#   a DEN-scope any_owned.                              #
#                                                       #
#   fire_only_once is engine-wide, not per country, so  #
#   every event here is guarded by a country flag that  #
#   each of its own options sets.                       #
#                                                       #
#########################################################
