#########################################################
#                                                       #
#   The Unitarian-Federal Wars and the rise of Rosas    #
#   1828-1835 (GVG)                                     #
#   ids 1002800-1002804                                 #
#                                                       #
#   Fills the nine-year hole between the Cisplatine     #
#   War (URUFlavor.txt 46410-46421) and the first ARG   #
#   flavour event (ARGFlavor.txt 46601, 1844). The      #
#   civil war is fought by the engine's rebels, the     #
#   Carlist way (SPAFlavor.txt 37711, PORMiguelistGVG), #
#   not by a scripted release + war: no tag is          #
#   released and no province is taken from an owner.    #
#                                                       #
#   Handoff: ARGFlavor.txt 46601 (Facundo, 1844),       #
#   46605 and 46610 (the Urquiza / Caseros chain of     #
#   1850) all require a presidential_dictatorship, so   #
#   1002804 option A wires this chain into them and     #
#   option B deliberately closes them off.              #
#                                                       #
#   1002804-A clears liberal_constitution AND sets      #
#   conservative_constitution in the same block, or     #
#   SouthAmericaFlavor.txt 97095 would fire within a    #
#   month and overwrite the government and reforms.     #
#                                                       #
#########################################################
