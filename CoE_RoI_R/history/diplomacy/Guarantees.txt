# guaranteed party). Victoria 2 ships this file empty in vanilla, so the

# does not know it, these entries are inert and will show in error.log at
# load. UNVERIFIED IN-GAME - check the log on the next launch and delete the
# file if it complains. See docs/design/vienna-settlement-1821.md.

# Deliberately excluded: the German Confederation's mutual defence (already
# modelled as the two full alliance webs in 'German Confederation.txt'), and

# vassal has no clear engine meaning).
